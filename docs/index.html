The one idea

A genome is a script. Sequencing turns it into text. Analysis turns text into tables, and tables into claims with uncertainty.

  • Python is the language of the text and pipeline layer (reads, sequences, files, tools).
  • R is the language of the table and statistics layer (counts, tests, figures for a paper).
  • You will read both. You will write whichever fits the step you are on.

Every step of the lecture, and every exercise of the lab, is done twice — once in each language — on the same real data: human chromosome 22 (GRCh38), the gene COMT, 5,000 real RNA-seq reads, and the eight-sample airway RNA-seq experiment used in the DESeq2 tutorial.

How to use this site

  1. Click Run Code in any grey cell. Edit the code and run it again — nothing you do here can break anything.
  2. Every lab exercise has a Hint and a Solution button. Try before you click.
  3. To keep your work, copy your code into a text file, or use the download links on the Setup page to run the same code locally in Jupyter or RStudio.
  4. ChatGPT is allowed (TRACE prompting, as in the proposal). Copilot-style autocomplete is not used in this lab — the point is to read every line.
