2a · GC content

Fill in the blanks so the cell prints the GC content as a percentage.

Python

Hint

cds.count("C") counts C’s; len(cds) is the length.

g = cds.count("G")
c = cds.count("C")
gc = (g + c) / len(cds)
print(round(gc * 100, 1), "%")     # 61.8 %

R

Hint

%in% tests membership in a vector: c("G", "C").

bases <- strsplit(cds, "")[[1]]
gc <- mean(bases %in% c("G", "C"))
cat(round(gc * 100, 1), "%\n")     # 61.8 %

Both languages must print 61.8 %. The human genome averages about 41 % — COMT is a GC-rich gene on a GC-rich chromosome.

2b · Reverse complement

Write the reverse complement of cds and print its first 20 letters.

Python

Hint

reversed(cds) walks the string backwards.

complement = {"A": "T", "T": "A", "G": "C", "C": "G"}
rc = "".join(complement[b] for b in reversed(cds))
print(rc[:20])          # TCAGGGCCCTGCTTCGCTGC

R

Hint

complement[bases] looks up every base at once; rev() reverses a vector.

complement <- c(A = "T", T = "A", G = "C", C = "G")
rc <- paste(rev(complement[bases]), collapse = "")
cat(substr(rc, 1, 20), "\n")   # TCAGGGCCCTGCTTCGCTGC

The reverse complement must start with TCA — because the CDS ends with the stop codon TGA.

2c · Translate, then mutate codon 158

Run the setup cell (codon table + translate). Then complete the exercise: print codon 158 and its amino acid, change its first letter G→A (this is rs4680), and print the new amino acid.

Python

Hint

Replace the first letter with "A". Amino acid 158 is index 157 in Python.

i = (158 - 1) * 3
codon = cds[i:i+3]
print("codon 158:", codon, "->", codon_table[codon])      # GTG -> V
mutant = cds[:i] + "A" + cds[i+1:]
print("mutant   :", mutant[i:i+3], "->", translate(mutant)[157])   # ATG -> M

R

Hint

substr(x, i, i) <- "A" replaces one letter in place. Amino acid 158 is position 158 in R.

i <- (158 - 1) * 3 + 1
codon <- substr(cds, i, i + 2)
cat("codon 158:", codon, "->", codon_table[codon], "\n")    # GTG -> V
mutant <- cds
substr(mutant, i, i) <- "A"
cat("mutant   :", substr(mutant, i, i + 2), "->", substr(translate(mutant), 158, 158), "\n")  # ATG -> M

The protein must start with MPEAPPLLLA, be 271 aa long, and codon 158 must be GTG (V) → ATG (M). This is Val158Met, the COMT variant that lowers enzyme activity 3–4 fold.

3a · Decode quality and plot the mean per position

Python

Hint

Phred+33 encoding: ord(char) - 33.

total = sum(ord(q[i]) - 33 for q in quals)

R

Hint

utf8ToInt() gives the ASCII codes; subtract 33.

Q <- t(sapply(quals, function(s) utf8ToInt(s) - 33))

Mean Q starts around 33 at position 1, peaks near 37, and drifts down to about 35 by position 100. Q = 30 means a 1-in-1000 error probability.

4c · Mismatches: which look like real variants?

chr22_mismatches.tsv lists every position where ≥ 2 reads disagree with the reference. Filter to depth ≥ 10 and allele fraction between 0.3 and 0.7 (what a heterozygous SNP looks like). Then tabulate the most common substitution types across the whole table.

Python

Hint

0.3 and 0.7. In pandas, combine conditions with & and parentheses.

het = mm[(mm["depth"] >= 10) & (mm["alt_fraction"] >= 0.3) & (mm["alt_fraction"] <= 0.7)]   # 8 rows

R

Hint

0.3 and 0.7; combine with &.

het <- mm[mm$depth >= 10 & mm$alt_fraction >= 0.3 & mm$alt_fraction <= 0.7, ]   # 8 rows

Only 8 of 1,097 mismatch sites look heterozygous. The two most common substitutions are T>C and A>G — the same change seen from the two strands.

5b · The 19,271-tests trap

Run a t-test on every gene. Count how many have p < 0.05. Then shuffle the sample labels and count again.

Python

Hint

0.05.

print("p < 0.05:", (p < 0.05).sum(), "of", len(p))    # ~1800 real, ~1200 shuffled

R

Hint

0.05. (This cell takes ~10 s in the browser.)

cat("p < 0.05:", sum(p < 0.05, na.rm = TRUE), "of", length(p), "\n")   # ~1500 real, ~600 shuffled

With random labels, hundreds to over a thousand genes still pass p < 0.05 (the exact number depends on the shuffle) — about 5 % of 19,271 is what “p < 0.05” promises for false positives, and some shuffles accidentally line up with the four donors, which adds more. Now apply Benjamini–Hochberg: p.adjust(p, "BH") in R; in Python sort p, multiply by n/rank. How many survive at FDR 0.05?
