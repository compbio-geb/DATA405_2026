Part 1 · Why two languages?

Python (Guido van Rossum, 1991) was designed as a general-purpose language that reads like pseudocode. When DNA sequencing started producing text at scale (2005–2010), Python’s string handling and its “glue” nature made it the language of pipelines: reads, files, tools, web services.

R (Ross Ihaka & Robert Gentleman, University of Auckland, 1993) is the open-source descendant of S (John Chambers, Bell Labs, 1976), a language built for statistics. In 2001 Bioconductor was founded on R, and since then most statistical methods for genomics (limma, edgeR, DESeq2) have been published as R packages first.

Python R
Born 1991, general purpose 1993, statistics (from S, 1976)
Natural unit string, list, dict vector, data frame
Genomics home Biopython, pysam, scanpy, PyTorch Bioconductor: DESeq2, edgeR, Seurat
Plots matplotlib (a library) plot() is built into the language
Where you meet it pipelines, machine learning, web statistics, figures for the paper

Neither is “the real one”. A typical genomics project runs a Python (or shell) pipeline to produce a table of counts, then an R notebook to test hypotheses and draw the figures.

The four differences that actually matter

  1. Indexing starts at 0 in Python and at 1 in R. dna[0] in Python is the first letter; substr(dna, 1, 1) in R is the first letter. Half of all coordinate bugs in genomics come from this. (BED files are 0-based; GTF/VCF files are 1-based.)
  2. Python works on one string; R works on vectors. In R, almost everything is a vector, so mean(bases %in% c("G","C")) computes GC content without a loop. Python needs a loop or str.count.
  3. Assignment: = in Python, <- in R (R also accepts =).
  4. Blocks: Python uses indentation; R uses { }.

A FASTQ record is four lines: name, sequence, +, quality. Each quality character encodes a Phred score: Q = ord(char) − 33, and the probability the base is wrong is 10^(−Q/10). reads_5k.fastq has 5,000 real 100-nt reads from ENCODE.

Part 7 · Working like a scientist

  • Ecosystems. Python packages come from PyPI (pip install) or conda; R packages from CRAN (install.packages) and Bioconductor (BiocManager::install("DESeq2")). A tool published in a paper is usually on one of these.
  • Notebooks are lab notebooks. Jupyter (.ipynb) and Quarto/R Markdown (.qmd, .Rmd) keep code, output and your comments together. This website is a Quarto document.
  • Reproducibility. Record versions (pip freeze, sessionInfo()), set random seeds, never edit raw data by hand, keep the script that made every figure.
  • ChatGPT writes code; you verify it. Use TRACE prompting, then run the code on a case you already know the answer to — COMT codon 158 must be GTG; the protein must start with M — before you trust it on new data.

The five bugs that bit real papers

  1. 0-based vs 1-based coordinates (BED vs GTF/VCF).
  2. Strand: a k-mer from the minus strand never matches unless you reverse-complement.
  3. Reference build: GRCh37 positions pasted into a GRCh38 file (rs4680 is chr22:19,963,748 in GRCh38 but 19,951,271 in GRCh37).
  4. Excel turns gene names into dates: SEPT7 → “7-Sep”, MARCH1 → “1-Mar”. About one fifth of published supplementary gene lists contain this error (Ziemann et al. 2016), which is why HGNC renamed these genes in 2020 (SEPTIN7, MARCHF1).
  5. Silent type coercion: a column read as text because one row says “NA”; a p-value column sorted as strings (“1e-10” after “0.5”).
